TinyDecide is a zero-dependency JavaScript library that sits in front of your decision API. Every call still goes to your API on day one. After enough answers are logged, TinyDecide trains a small local model and certifies — using conformal prediction — that it agrees with your API at least 98% of the time. From then on, calls it is sure about are answered locally in about 10 µs instead of hundreds of milliseconds.

<CodeGroup>

```bash npm
npm install tinydecide
```

```bash bun
bun add tinydecide
```

</CodeGroup>

```js
import { shadow } from 'tinydecide';

const classify = shadow('support', (text) => api.classify(text));

// Drop-in replacement — same answers, zero latency after the model certifies
await classify('my card was charged twice');
```

## Why TinyDecide?

Decision APIs — LLM classifiers, routing models, intent detectors — are accurate but slow and expensive. TinyDecide lets you keep using your API as the reference while a local model handles the easy calls:

<CardGroup cols={3}>
  <Card title="~10 µs locally" icon="bolt">
    vs. 400–600 ms from a remote model. No network round-trip.
  </Card>
  <Card title="≥98% agreement" icon="circle-check">
    Certified at 95% confidence before the local model goes live.
  </Card>
  <Card title="Zero dependencies" icon="feather">
    12 KB gzipped. Runs in Node, Bun, browsers, and edge runtimes.
  </Card>
</CardGroup>

## Get Started in Three Steps

<Steps>
  <Step title="Install and wrap your API">
    Add TinyDecide to your project and wrap your existing decision function with `shadow()`. Every call still goes to your API — nothing changes yet.

    ```js
    import { shadow } from 'tinydecide';
    const classify = shadow('support', (text) => yourApi.classify(text));
    ```
  </Step>
  <Step title="Let it learn">
    TinyDecide silently logs your API's answers. After 2,000 responses it compiles a local model and certifies whether it meets the agreement target. You'll see one log line when it's ready.

    ```
    [tinydecide] support: compiled from 2,000 answers: answers 60% of calls locally,
    with ≥ 98% agreement with your API certified at 95% confidence. 0.16 MB, 8.1 µs per call.
    ```
  </Step>
  <Step title="Calls route automatically">
    Calls the model is confident about are answered locally. The rest still go to your API. A live audit continuously re-checks agreement — if your API's behavior changes, every call reverts to it until a new model certifies.
  </Step>
</Steps>

## Try it Now — No API Key Needed

```bash
npx tinydecide try
```

This runs a 15-second simulation: TinyDecide wraps a simulated support-ticket classifier, learns it, then watches its behavior change — and catches the drift.
